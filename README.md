# PassionTrack

PassionTrack is a **modern job portal** designed to streamline job searching and recruitment. Built with **React.js, Tailwind CSS, Supabase, and Clerk**, it provides a seamless experience for both job seekers and employers.

## Features

### For Job Seekers:
- **Browse & Apply**: Easily search and apply for job listings.
- **Track Applications**: Monitor the status of job applications.
- **Secure Profile Management**: Manage resumes and personal details securely.

### For Employers:
- **Post Jobs**: Create and manage job listings.
- **Application Management**: Track and review applicants.
- **Candidate Filtering**: Identify the best talent efficiently.

### General Features:
- **Secure Authentication** using Clerk.
- **Scalable Data Storage** powered by Supabase.
- **Automated Emails** for notifications and updates.
- **Responsive UI** with Tailwind CSS for a modern look.

## Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Backend & Database**: Supabase
- **Authentication**: Clerk

## Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/luk027/passion-track.git
   ```
2. Navigate to the project directory:
   ```bash
   cd passion-track
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up environment variables for Supabase and Clerk.
5. Start the development server:
   ```bash
   npm run dev
   ```
